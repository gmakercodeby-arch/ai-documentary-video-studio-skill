## 3. Stage 1 — The 8-Act Retention Script Architecture (~2,900–3,200 Hindi Words)

Never generate a 20-minute script in a single rushed prompt. Write **Act-by-Act** (each Act = `340–420` Hindi words = `~2.1–2.6 minutes` = **1 single Gemini TTS API call**!).

### Exact 8-Act Blueprint
1. **Act 1 (`00:00–01:45` | ~280 words) — Cinema Cold-Open + 16-Min Open Loop:**
   - **ZERO channel intro** (never say *"Hello dosto welcome to..."*).
   - Drop straight into a tense sensory scene in present tense (*"रात के सन्नाटे में किसान खेत पर पहुंचता है..."*).
   - Plant a **video-end open loop** around 01:05 (*"लेकिन क्या इसमें कोई बड़ा पेंच भी है? वो मैं वीडियो के आखिर में बताऊंगा, तो टिके रहिए।"*).
2. **Act 2 (`01:45–03:30` | ~360 words) — Relatable Analogy + Scale of Crisis:**
   - Explain the core physics/problem using an everyday metaphor (ATM machine, blocked drain, pressure cooker).
   - Drop official stats/reports + global comparison (Israel, Japan, USA) + **Open Loop #2**.
3. **Act 3 (`03:30–06:00` | ~400 words) — Hero Origin + Emotional Stakes:**
   - Introduce the real engineers/inventors/builders and the human pain behind the problem.
   - Reveal the hero machine/technology name.
4. **Act 4 (`06:00–07:45` | ~340 words) — The Villain (Why Old Solutions Failed):**
   - Break down 2–3 numbered flaws of traditional methods (gives crisp on-screen callouts like `"1. GETS CLOGGED"`, `"2. ₹1.5 LAKH COST"`).
5. **Act 5 (`07:45–10:30` | ~420 words) — The 3-Step Engineering Reveal (Heart of Video):**
   - Explain Step 1, Step 2, Step 3 with vivid **3D cutaway** and **medical/everyday analogies** (e.g., blocked heart artery).
   - Drop the shocking cost/performance comparison (split-screen visual!).
6. **Act 6 (`10:30–12:45` | ~380 words) — Conflict + Real-World Proof (Case Study):**
   - Show skepticism/failure risk → then a real named person/project with concrete Before vs After numbers.
7. **Act 7 (`12:45–14:30` | ~340 words) — Massive Scale & Business/Global Impact:**
   - Show map/numbers (states, countries, crores/billions, jobs). **Accelerate cut speed to `1.6s/cut`!**
8. **Act 8 (`14:30–17:30` | ~400 words) — Loop Payoff (Honest Limitations) + Comment Bait + Mandatory 1-Click Website CTA (LOCKED v4.0):**
   - Pay off Act 1's promised *"पेंच"* with honest caveats/future outlook (builds huge subscriber trust!).
   - Peak cut energy → Inspiring takeaway → **Engagement Comment Bait:** *"अगला वीडियो किस टॉपिक पर होना चाहिए? नीचे कमेंट करके ज़रूर बताइए!"*
   - **MANDATORY Final Lead-Gen Closing Line (NEVER SKIP!):** Always end the script with:
     > *"और हाँ, अगर आप भी ऐसा ही सिनेमैटिक वीडियो सिर्फ एक क्लिक में बनवाना चाहते हैं, तो नीचे डिस्क्रिप्शन में दी गई वेबसाइट पर ज़रूर विज़िट करें!"*
   - Pair this closing line with a sleek Playwright glassmorphism **Website CTA lower-third card** on screen!

### Mandatory TTS-Safe Hindi Script Rules (Zero Pronunciation Bugs!)
- Write **all technical acronyms phonetically or spaced cleanly** so TTS never misreads `PSI` as `PSE` (write `पी-एस-आई` or consistent `PSI`, test any rare term).
- Write numbers naturally for Hindi speech (`₹15,000` → `15 हजार रुपये`, `4.5` → `साढ़े चार`, `50%` → `50 प्रतिशत`).
- Use `—` (em-dash) and `...` sparingly ONLY on real punchline drops so the narrator stays at `~161 WPM` instead of slowing down.
